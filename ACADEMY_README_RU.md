# SHINOBI ACADEMY V1 — интерактивное обучение

Изменения подготовлены на основе **предоставленного ZIP** `shinobi-arena-main (3).zip`, а не удалённого репозитория. Исходные визуальные ассеты, боевой движок и готовый расширенный учебный матч сохранены.

## Важное предупреждение об онлайн-игре

В исходном ZIP присутствуют офлайн-режимы против CPU и для двух игроков на одном устройстве. Полноценный клиент онлайн-матчей / WebSocket-механизм в нём не найден. Поэтому **не заменяйте автоматически текущий онлайн-проект файлами из FULL.zip**, если онлайн уже работает в более новой версии на GitHub. Иначе можно потерять изменения, отсутствующие в присланной базе.

В этом случае используйте архив **INTEGRATION.zip**: два новых файла и отдельный патч только с тремя целевыми изменениями действующего игрового JS и двумя ссылками на новые файлы в HTML. Сверяйте патч с вашей актуальной веткой; при конфликте переносите изменения вручную. Если текущий онлайн-клиент сильно отличается, для корректного переноса потребуется именно его актуальный ZIP.

## Что видит новый игрок

0. Короткое введение: роль капитана и активный учебный жребий 6 : 2.
1. «Забрать» (KEEP): получить открытую карту в свой отряд.
2. «Отдать» (PASS): передать открытую карту сопернику.
3. Связь персонажей: изучить составную карту Team 7, выбрать её лидера.
4. Свитки: выбрать тактический свиток и назначить бойцу.
5. Арена: выполнить учебную прокрутку и увидеть эффект поля.
6. Бой: выбрать бойца, подтвердить выбор, провести дуэль на основе существующего `resolveCombat()`.

На каждом этапе есть краткое объяснение, непосредственное действие, обратная связь, подсказка, возможность вернуться назад. Ошибки в учебной симуляции исправимы; прогресс хранится локально. По завершении можно открыть режимы или пройти прежний **полный** учебный матч против Easy CPU.

Всё в рамках Академии — **локальная симуляция обучения**, не настоящее изменение состава, рейтинга, экономики, онлайна, статистики либо сохранённого матча. В игре случайность настоящая, а некоторые результаты в Академии намеренно предопределены для ясности.

## Что изменено

- `index.html`: включение CSS и JS Академии, ясный первый призыв к действию.
- `js/game-vk-bridge.js`: интеграция начала игры / повторного открытия обучения / пропуска в новую Академию. Основной игровой движок не переписан.
- `css/academy-onboarding.css`: новый адаптивный интерфейс (включая мобильную вертикальную прокрутку, подсказку «Показать действие» для очень низких экранов, эффекты, снижение анимации для пользователей с соответствующей настройкой).
- `js/academy-onboarding.js`: независимая логика шести заданий и вводного интерактивного жребия.

## Установка

**FULL.zip**: содержит всю игру на основе присланного источника. Его содержимое нужно распаковать **в корень** GitHub-репозитория только тогда, когда вы точно знаете, что текущая ветка соответствует присланной офлайн-базе. Не создавать дополнительную внешнюю папку `shinobi-arena-main`.

**INTEGRATION.zip**: предназначен для переноса в более новую версию с онлайном. В ZIP лежат `css/academy-onboarding.css`, `js/academy-onboarding.js`, `academy-integration.patch` и этот README. При идентичной базе патч можно применить командой `git apply academy-integration.patch`; на другом исходнике выполните выборочный перенос, не перезаписывайте чужие изменения в `js/game-vk-bridge.js`. Проверяйте исходный HTML: две добавленные строки подключают CSS и JS в определённом порядке.

По завершении деплоя очистите кэш HTML или проверьте новую версию в приватном окне. Для ручной проверки: запуск новой игры → активный жребий → шесть заданий → экран завершения → учебный полный матч или выбор режима → повторный вход.

## Ограничения и модерация

Программный тест в Chromium с имитацией экранов 1366×768, 390×844, 320×568, 844×390 подтвердил прохождение всех заданий, базовую правильность переходов, отсутствие JavaScript page errors и горизонтального переполнения на этих экранах. Дополнительно пройден переход в существующий учебный матч и проверено, что профиль до/после прерванного сценария не изменился. Для маленьких телефонов проверена прокрутка к кнопке действия.

Это не означает теста в реальных Android, iOS, VK Mini Apps и Одноклассниках. Не подтверждены реальная платформа, сеть, онлайн-соединение и решение модератора. До повторной отправки обязательно пройти обучение в самом кабинете/клиенте VK на ПК и телефоне, проверить визуально кнопки, звуки, изображения, полноэкранный режим, а также обычные матчи.

## Разработчикам

`window.SHINOBI_ACADEMY` предоставляет `open({restart:true})`, `gatePlay()`, `completed()`, `audit()`, `startTraining()`, `skipAndPlay()`, `reset()`.

Ключ локального прогресса: `shinobi_academy_progress_v1`. Для ручного теста нового пользователя в консоли DevTools достаточно вызвать `SHINOBI_ACADEMY.reset()` (используйте только в тестовом профиле). Для повторного прохождения в интерфейсе воспользуйтесь прежним пунктом «Обучение» в настройках.
